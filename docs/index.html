QUICK START · 05 MINUTES

From empty project to verified SDK.

  1. 01

    Install

    Add the package from Git URL and open Sketch SDK → Settings.

  2. 02

    Configure

    Enter platform IDs, server credentials and remote defaults.

  3. 03

    Verify

    Press Save & Verify. The editor checks runtime paths and release requirements.

  4. 04

    Integrate

    Use one adapter. Keep rewards and entitlements in your DataBlock/backend.

SketchAds.ShowRewarded("double_coins", granted => {
    if (granted) wallet.GrantReward();
});
